This calls the paid model. Six runs: two clean tasks per arm, then one interrupted queue task per arm. Each run has a 12-minute wall limit, 40 model-call cap, 160k reported-token stopping threshold. Protocol v3 preserves the real model capabilities and runtime's actual per-request output and recovery policy instead of overriding per-call output limits. Root, worker, auditor and auxiliary model calls use the same wrapper; the token threshold is checked between calls and can overshoot with a completed/in-flight request. A killed or failed request may lack provider usage. Recovery waits 95 seconds for the durable lease; that wait and both attempts share the original wall/call/token allowance.

The verifier resides outside agent workspaces and checks the stated public contract independently. Agents receive requirements and can write their own tests. Failures and timeouts are retained, never silently replaced with reruns. Results include the full per-check outcomes, usage observations and journals. Credentials are loaded in memory from the repository configuration and are not copied into fixtures or reports. `.runs` is ignored.

Protocols v2/v3 create each workspace under the system temporary directory, initializes its own Git repository, commits the initial requirements and fixtures, and asserts its Git root. The workspace path is stored in the case manifest. This is required for child worktree isolation: an ignored subdirectory inside the Paw repository is not a valid independent fixture. Initial diagnostic v1 data is explicitly invalidated and excluded from comparisons. The v3 runtime includes the Windows equivalent-root casing fix; both arms use that same implementation.
