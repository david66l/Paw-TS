# 输出额度改为跟随模型：2026-09-07

桌面主执行、使用独立模型的子 Agent，以及 Paw Next 的默认输出预留，现统一读取所选模型的 `capabilities.maxOutputTokens`。GLM-5.3-Flash 当前能力配置为 128000，因此首次执行请求和续写均可使用 128000；其他模型使用自己的声明值。只有未声明输出能力时才回退到 8192。

移除了普通执行路径固定 8192 的限制，也移除了续写模块的 32000 默认值和 64000/128000 分档限制。上下文规划器同步预留模型输出额度，续写不会越过模型能力及当前运行已预留的额度。显式指定较小额度的辅助请求仍保留其协议限制。

本次保持模型选择和思考强度配置不变。新增离线检查覆盖 GLM 流式请求的实际 `max_tokens`、截断续写、思考状态保留、不同父子模型及未知能力回退；运行时与桌面回归也验证了同配置的会话延续和恢复。没有将之前的 high 参数实验当作此次真实模型效果证据。

输出策略版本改为 `paw.model-output-recovery.v2:native:f8192:c3`，并进入运行配置指纹。已有检查点不被改写：旧策略下未结束的运行无法以新指纹直接恢复，需要保留旧版本恢复或在新版本新建任务。同配置的新运行可以正常继续和恢复。

此前的 [RETEST.md](RETEST.md) 与 [MODEL-TUNING.md](MODEL-TUNING.md) 都是在旧输出策略下取得的历史结果。不能把那些任务分数当作新策略的测量结果；旧参数探针中的 max-native 与 max-32768 在新默认额度下也不再构成同样的对照。
