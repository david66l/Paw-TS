# Paper skin assets

- `paper-fibers-v1.webp` and `lavender-sprig.webp`: reused from the owner's Louis.dev / MyBlog website (`public/paper-fibers-v1.webp` and `public/lavender/sprig-3.webp`).
- Inter and Newsreader: Latin variable font subsets from MyBlog's installed `@fontsource-variable/inter` and `@fontsource-variable/newsreader` packages. Their SIL Open Font License texts are included alongside the fonts.

All assets are bundled locally by Vite. Chinese text falls back to system fonts.
